# Background Video

Letakkan file video futuristik di sini dengan nama:

- `bg.mp4` (utama)
- `bg.webm` (alternatif untuk Firefox)

**Spesifikasi yang disarankan:**
- Resolusi: 1920x1080
- Format: MP4 (H.264) + WebM
- Durasi: 10-30 detik (loop)
- Ukuran: < 20MB
- Tema: Futuristic, cyber, neon, space, technology

**Sumber video gratis:**
- https://pixabay.com/videos/search/futuristic/
- https://www.pexels.com/search/videos/technology/
- https://coverr.co/

Jika video tidak disediakan, website akan menggunakan **animated gradient fallback** secara otomatis.
