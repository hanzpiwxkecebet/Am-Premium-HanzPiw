Cara paling pasti kalau impor otomatis gagal: buka pack di browser, salin alamat tiap gambar stiker.
Stiker Tersedia
Pengaturan Sistem (Owner)
Berlaku untuk user yang belum memilih sendiri lewat tombol speaker. Pilihan user selalu didahulukan.
Setiap lagu: judul, kategori (mis. OLD, SAD), dan sumber audio: file yang diupload (MP3, M4A, OGG, WAV, FLAC; maks 12MB per lagu) atau link langsung ke audio (https). Setelah upload, tekan Simpan Semua Pengaturan. Pilihan "ALL" otomatis berisi semua lagu. Lagu pertama yang diputar diacak untuk tiap user, lalu lanjut otomatis. User membuka playlist dengan menekan equalizer. Maksimal 60 lagu.
Dipakai kalau playlist kosong. Link langsung ke file audio. Kosongkan untuk audio bawaan.
Background Website
Nonaktif = tampilan bawaan seperti sekarang. Aktif = gambar di bawah dipakai sebagai latar di semua halaman.
Link langsung ke gambar (https). Kalau gambarnya gagal dimuat, website otomatis memakai tampilan bawaan.
Gambar otomatis dikecilkan (maks 1600px) supaya website tetap cepat.
Belum ada gambar
Tampilan Website (RGB)
Berlaku untuk semua user di SEMUA menu. Abu-abu = tampilan sekarang; RGB = background (gambar dideteksi dulu lalu diberi lapisan RGB), kartu, tombol, form, menu bawah, tabel, dan teks berwarna RGB bergerak tanpa abu-abu. Di mode RGB tema terang otomatis memakai palet RGB gelap.
